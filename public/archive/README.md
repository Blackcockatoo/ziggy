# Archive images

Approved image, document and audio files go here, then get referenced from a
media record's `src` as `/archive/<filename>`.

Nothing lands in this folder without:

1. permission from whoever owns the object or appears in the photograph, and
2. a matching record in `src/content/` carrying alt text, a caption and an
   evidence status.

Keep the original filenames from Rob where you can — they are provenance.
